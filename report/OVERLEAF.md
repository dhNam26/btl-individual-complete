# Compiling the IEEE Conference Report on Overleaf

This report uses standard `IEEEtran` (`\documentclass[conference]{IEEEtran}`) and standard `pdflatex` — **no custom fonts or XeLaTeX setup required**!

## Steps on Overleaf
1. Create a new blank project on [Overleaf](https://www.overleaf.com).
2. Upload the contents of this `report/` folder (keeping `main.tex`, `latexmkrc`, and the `figures/` folder containing all `fig*.pdf` files).
3. Ensure Compiler is set to **pdfLaTeX** (default on Overleaf) and Main document is `main.tex`.
4. Click **Recompile**.

## Local Preview (No LaTeX Required)
Open `report_preview.html` in any browser (Chrome/Edge) to inspect the formatted IEEE two-column paper with embedded vector figures, or print directly to PDF (`Ctrl+P -> Save as PDF`).
